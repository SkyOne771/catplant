## Project entry

**Catplant — Browser Gardening Game**  
JavaScript · SVG · CSS · Vite · Playwright · GitHub Actions · Caddy

[Source code](https://github.com/SkyOne771/catplant) · [Live demo](https://vps-bbba68b4.vps.ovh.ca/catplant/)

## Short description

Built and deployed a responsive gardening game with a ten-crop care cycle, device-local progress, and an animated cat character. Added cross-browser end-to-end tests and a CI workflow for formatting, production builds, and gameplay verification.

## Optional bullets

- Implemented crop lifecycle transitions, next-action tool indicators, browser persistence, and confirmed progress reset in vanilla JavaScript.
- Created SVG scenery and a four-leg character animation with click-to-move controls, direction changes, paw prints, and reduced-motion support.
- Adapted tooltips, controls, and the expanded play area for desktop and phone layouts.
- Added Playwright coverage across Chromium, Firefox, and a mobile viewport, plus GitHub Actions checks.
- Deployed static releases behind HTTPS using Caddy, with atomic release switching, proxy validation, and retained assets for older browser tabs.

## Useful demo sequence

1. Choose a seed, then plant, water, tend, and harvest it.
2. Click another point in the garden to demonstrate the walking rig.
3. Open the crop collection and reload to show persisted progress.
4. Resize to a phone viewport and show that crop information stays outside the scene.
5. Open the repository’s tests and CI workflow to explain how the interactions are verified.
